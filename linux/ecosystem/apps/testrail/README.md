# `epicmorg/testrail`

Self-hosted [TestRail](https://www.testrail.com/) images, generated by `bin/ansible`
(role `gurock.testrail`) - one directory per TestRail release.

## What's inside

* based on [`epicmorg/apache2:php<ver>`](https://github.com/EpicMorg/docker/tree/master/linux/ecosystem/apps/apache2):
  Apache2 + PHP-FPM over a unix socket, run by supervisor; ionCube loader from `epicmorg/php`;
* the PHP line follows what each TestRail release supports:

  | TestRail | PHP | Cassandra PHP extension |
  | -------- | --- | ----------------------- |
  | `3.1.0` ... `4.2.0` | `5.5` | - |
  | `4.2.1` ... `5.3.0` | `5.6` | - |
  | `5.4.0` ... `5.6.0` | `7.0` | - |
  | `5.7.0` ... `6.3.1` | `7.1` | - |
  | `6.4.0` ... `6.7.2` | `7.2` | - |
  | `7.0.0` ... `7.5.3` | `7.4` | Gurock's prebuilt DataStax driver |
  | `8.0.0` ... `9.1.0` | `8.1` | PHP 8 fork of the DataStax driver, built from source |

* supervisor programs: `php-fpm`, `apache2`, `testrail-task` (background task every
  `TR_DEFAULT_TASK_EXECUTION` seconds, default `60`);
* on every start the TestRail code is re-extracted into `/var/www/testrail`;
* ports `80` / `443`.

Tags per release:

* `<version>` - TestRail;
* `auth-ad-<version>` / `auth-ldap-<version>` - plus the Active Directory / LDAP authentication
  script and the PHP `ldap` extension (own OpenLDAP client built against PHP's OpenSSL - 2.6, or 2.4 on the
  PHP 5.x lines whose OpenSSL 1.0.2 OpenLDAP 2.5+ no longer supports). Configure
  the script and mount it as `/var/www/testrail/custom/auth/auth.php`.

TestRail 7.0+ needs a Cassandra server - e.g. [`epicmorg/cassandra:3.11`](https://github.com/EpicMorg/docker/tree/master/linux/ecosystem/apps/cassandra/3.11).
Each version directory has its own README with the exact contents.

## Usage

```yml
services:
  testrail:
    image: epicmorg/testrail:9.1.0.1025
    restart: always
    ports:
      - "80:80"
    volumes:
      - ./custom/auth/auth.php:/var/www/testrail/custom/auth/auth.php:ro   # auth-* tags only
      - ./attachments:/opt/testrail/attachments
      - ./audit:/opt/testrail/audit
      - ./logs:/opt/testrail/logs
      - ./reports:/opt/testrail/reports
      - ./config:/var/www/testrail/config
    depends_on:
      - mysql
      - rabbitmq
      - cassandra
    environment:
      - TR_DEFAULT_TASK_EXECUTION=60

  mysql:
    image: mysql:8
    restart: always
    volumes:
      - ./mysql/my.cnf:/etc/mysql/my.cnf
      - ./mysql/data:/var/lib/mysql
    environment:
      MYSQL_ROOT_PASSWORD: password

  cassandra:
    image: epicmorg/cassandra:3.11
    restart: always
    ulimits:
      memlock: -1
      nproc: 1048575
      nofile: 100000
    volumes:
      - /etc/localtime:/etc/localtime:ro
      - /etc/timezone:/etc/timezone:ro
      - ./cassandra:/var/lib/cassandra

  rabbitmq:
    image: rabbitmq:3-management
    restart: always
    environment:
      - RABBITMQ_DEFAULT_USER=testrail
      - RABBITMQ_DEFAULT_PASS=testrail
    volumes:
      - ./rabbitmq:/var/lib/rabbitmq
```

Installation and database setup: see the [TestRail documentation](https://support.testrail.com/) for the server edition.
